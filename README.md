# 체스 놀이

7인치 태블릿용 어린이 게임 모음. 홈 화면에 설치해서 앱처럼 쓰는 웹앱(PWA)입니다.

- ♟ 체스 (`/`): 컴퓨터 대결(쉬움/보통/어려움) / 둘이서 같이, 잡은 말 트레이, 이어하기
- 🪨 알까기 (`/algakki/`): 알을 뒤로 당겼다 놓아 튕기기, 컴퓨터 3단계 / 둘이서
- ✖️ 곱셈 몬스터 (`/multiply/`): 두 자리×한 자리 곱셈, 쪼개서 풀기 단계 학습, 몬스터 퇴치
- 세 게임이 하루 시간 제한과 부모 확인(기기 지문/화면 잠금, 없으면 PIN)을 함께 씁니다
- 게임마다 몇 대 몇 전적을 기록합니다 (이 기기의 브라우저 저장소 사용)

설치: 태블릿 Chrome에서 https://ivyrarara.github.io/chess/ 를 열고 메뉴에서 "홈 화면에 추가" 또는 "앱 설치".
